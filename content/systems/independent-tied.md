## When to use it

The default access scaffold for work on a building elevation. "Independent" means it has two rows of standards and doesn't rely on the wall for vertical support. It still needs **ties** to the building for lateral stability.

## Key requirements

- Choose a load class from the trade using it ([[load-classes]]) - for example, class 4 for brickwork.
- Tie pattern from the [[tg20]] compliance sheet or the design. Anchors are tested to [[tg4-anchors]].
- Brick guards or netting where materials are stored on the platform.
- Can be built in [[tube-and-fitting]] or a system scaffold ([[multidirectional-system]], [[cuplok]], [[kwikstage]]).

## Common pitfalls

- Overloading the top lift with bricks or roof tiles.
- Ties removed for window installation and not replaced.
